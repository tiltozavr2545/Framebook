# Бриф проекта: Framebook

> Личный дневник оценок фильмов и сериалов: ставишь свою оценку и сразу видишь, как она соотносится с Кинопоиском, IMDb и остальными.

**Документ фиксирует замысел на момент старта (2026-10-19)** — до первой
строки кода. Когда реальность разойдётся с замыслом, бриф не переписывается:
действующая схема будет в [data-model.md](data-model.md), история версий — в
[../CHANGELOG.md](../CHANGELOG.md), незакрытое — в
[future-development.md](future-development.md).

---

## 1. Зачем это нужно

Оценки фильмов у большинства людей размазаны: часть на Кинопоиске, часть на
IMDb, часть в заметках, часть в голове. Каждый сервис показывает свой рейтинг
и прячет чужие, и вопрос «насколько мой вкус совпадает с Кинопоиском, а
насколько с IMDb» задать некому.

Framebook — один список своих оценок, который не принадлежит ни одному из этих
сервисов, плюс все их рейтинги рядом. Отсюда и главные свойства:

- **Свои данные — свои.** Оценки лежат на устройстве и в Google Drive
  пользователя, а не на чьём-то сервере. Нет аккаунта, который можно
  потерять, и нет сервиса, который может закрыться вместе с историей оценок.
- **Сравнение — первичная функция, а не украшение.** Расхождение «моя − КП»
  — это колонка, по которой сортируется список, и основа статистики.
- **Калибровка оценки.** Через год шкала у человека «плывёт»: то, что раньше
  было 7, стало 8. Окно «что ты ещё оценил так же» сразу после оценки
  показывает, с чем новая оценка встаёт в один ряд, и даёт её поправить.

Аудитория — автор и пара друзей. Это снимает требования к публикации в
сторах, но не к аккуратности: оценки, накопленные за годы, терять нельзя.

## 2. Механика продукта

**Произведение (work).** Фильм, сериал, сезон или серия. Все четыре
оцениваются независимо: оценка сериала не вычисляется из оценок сезонов, а
сезона — из серий. У сериала и сезона рядом с собственной оценкой
показывается подсказка — среднее по уже оценённым частям («по сериям: 7.8»).

**Оценка.** От 1 до 10 с шагом 0.5. Шкала совпадает с Кинопоиском и IMDb, поэтому
сравнение — прямая разница без пересчёта. К оценке можно добавить
текстовую заметку.

**Окно калибровки.** Появляется сразу после сохранения оценки и показывает:

- произведения того же типа с **точно такой же** оценкой (несколько, недавние
  первыми);
- **соседей**: несколько произведений того же типа с ближайшей **существующей**
  оценкой выше и ближайшей ниже (не обязательно ±0.5 — если оценок 8.5 нет,
  соседом сверху будет 9).

Тип всегда тот же: фильм сравнивается с фильмами, серия — с сериями. Из
окна можно сразу поменять оценку.

**Внешние рейтинги.** На карточке рядом со своей оценкой: Кинопоиск, IMDb,
TMDB, Rotten Tomatoes, Metacritic — что из этого есть у конкретного
произведения и для чего у пользователя введены ключи. У каждого — разница
«моя − их».

**Списки.** «Мои оценки» (с сортировкой по дате, оценке, году, названию и по
расхождению с КП или IMDb) и «Хочу посмотреть». Оценка произведения убирает
его из «Хочу посмотреть».

**Статистика.** Распределение своих оценок, среднее отклонение от КП и IMDb
(со знаком и по модулю), средняя оценка по жанрам и десятилетиям.

**Синхронизация.** Вход через Google — только ради Drive. Без входа
приложение полностью работает, просто данные живут на одном устройстве.

## 3. Решения, принятые до старта

| Вопрос | Решение | Почему |
|---|---|---|
| Платформа | Flutter, Android; iOS отложен | Стек уже знаком по Amicus; раздача друзьям — APK, без сторов |
| Каталог | TMDB — основа (поиск, карточки, сезоны/серии, постеры) | Лучший открытый API с сериалами до уровня серий и с внешними id |
| Рейтинг КП | ПоискКино API (неофициальный, бывший kinopoisk.dev) | Официального публичного API у Кинопоиска нет |
| IMDb / RT / Metacritic | OMDb API по `imdb_id` | Единственный простой источник всех трёх; у IMDb открытого API нет |
| Ключи API | Пользователь вводит свои | Без сервера вшитый ключ извлекается из APK, а лимиты становятся общими на всех |
| Шкала | 1–10, шаг 0.5 | Прямое сравнение с КП и IMDb |
| Что оценивается | Фильм, сериал, сезон, серия — независимо | Сериал может быть хорош целиком и слаб отдельными сезонами |
| Локальный кэш | Мини-снимок в БД + вытесняемый кэш с TTL | Офлайн-список без хранения каталога |
| Drive | Синхронизация со слиянием, файл в `appDataFolder` | Несколько устройств; скрытая папка не мешается в Drive |
| Аудитория | Для себя и пары друзей | Раздача APK, OAuth-приложение Google без публичной верификации |

## 4. MVP

- Ввод и проверка ключей API (TMDB обязателен, остальные — опционально)
- Поиск по TMDB; карточка фильма/сериала; список сезонов; список серий сезона
- Внешние рейтинги на карточке, с кэшем и бюджетом запросов
- Оценка 1–10 / 0.5 с заметкой для фильма, сериала, сезона и серии
- Окно калибровки
- «Мои оценки» с сортировками, включая расхождение; «Хочу посмотреть»
- Статистика
- Синхронизация через Google Drive, экспорт/импорт в файл
- en/ru, тёмная тема

Всё остальное — в [future-development.md](future-development.md).

## 5. Риски, известные на старте

- **Доступность TMDB из России.** По пользовательским сообщениям
  `api.themoviedb.org` и CDN постеров из РФ местами недоступны без VPN или
  смены DNS. Если так и окажется, каталог придётся брать из ПоискКино, а
  `work_key` — строить от id Кинопоиска. Проверяется первым делом, на
  Этапе 0, до того как схема ключей закреплена. *(Снято на Этапе 0,
  2026-10-20: никто из пользователей не выходит в сеть с российского IP.)*
- **ПоискКино — неофициальный сервис** с бесплатным лимитом 200 запросов в
  сутки. Он может закрыться или поменять API (уже менял домен). Рейтинг КП
  поэтому — опциональная часть карточки, а не несущая.
- **Лимиты.** 200/сутки у ПоискКино и 1000/сутки у OMDb означают, что
  сортировку по расхождению для библиотеки в тысячу оценок нельзя построить
  за один вечер. Нужен бюджет запросов и постепенное фоновое обновление —
  см. [external-sources.md](external-sources.md).
- **Условия использования.** TMDB требует атрибуцию (текст и логотип в
  «О приложении») и разрешает некоммерческое использование; данные OMDb —
  CC BY-NC. Для личного приложения без монетизации это проходит; данные
  Кинопоиска через сторонний сервис — серая зона, для круга из трёх человек
  приемлемо.
- **OAuth Google в режиме Testing.** Пока приложение в консоли Google Cloud
  в статусе Testing, доступ выдаётся только добавленным тестовым
  пользователям, а refresh-токены живут 7 дней. Что выбрать — см.
  [operations.md](operations.md).
