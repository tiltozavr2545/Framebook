# Как получить ключи API

Пошаговая инструкция для каждого, кто ставит Framebook: и для разработчика,
и для друзей. Это перевод [api-keys.md](api-keys.md) для пользователей
приложения — оно открывает его, когда интерфейс на русском. Ключи бесплатные, у каждого свои. Почему приложение не
поставляется со своими ключами — в [project-brief.md](project-brief.md):
коротко, без сервера вшитый ключ достаётся из APK, а лимиты стали бы общими
на всех.

| Сервис | Обязателен | Что даёт в приложении | Время на получение |
|---|---|---|---|
| TMDB | **да** | поиск, карточки, сезоны и серии, постеры, рейтинг TMDB | 10–15 минут, ключ сразу |
| ПоискКино | нет | рейтинг Кинопоиска, сортировка по расхождению с КП | 2 минуты в Telegram |
| OMDb | нет | IMDb, Rotten Tomatoes, Metacritic | 5 минут + письмо с активацией |

Без ключа ПоискКино нет рейтинга КП. Без ключа OMDb нет RT и Metacritic, а
IMDb для фильмов и сериалов берётся из ПоискКино, если его ключ есть.
Подробно — в [external-sources.md](external-sources.md).

Формы на сайтах — по состоянию на октябрь 2026. Если поле называется
чуть иначе, ориентируйся на смысл.

## 1. TMDB (The Movie Database)

Делать **с компьютера**: TMDB прямо пишет, что регистрация ключа не
адаптирована под телефон.

### 1.1. Аккаунт

1. Зарегистрироваться на [themoviedb.org/signup](https://www.themoviedb.org/signup):
   логин, пароль, email.
2. Подтвердить email по ссылке из письма. Без этого раздел API не откроется.

### 1.2. Заявка на ключ

1. Открыть [themoviedb.org/settings/api](https://www.themoviedb.org/settings/api)
   (профиль → Settings → API) и нажать **Create** (или «click here» в тексте
   про запрос ключа).
2. Тип ключа — **Developer**. Professional — для коммерческих проектов, это
   не наш случай.
3. Прочитать и принять условия использования (**Accept**).
4. Заполнить форму. Всё на английском.

**О приложении:**

| Поле | Что вписать |
|---|---|
| Type of Use | **Mobile Application**. Если такого пункта нет — ближайший по смыслу (Personal / Other) |
| Application Name | `Framebook` |
| Application URL | `https://github.com/tiltozavr2545/Framebook` — годится всем, в том числе друзьям: это настоящая страница проекта |
| Application Summary | текст ниже, можно как есть |

Application Summary:

```
Framebook is a personal, non-commercial Android app for keeping my own
film and TV ratings and comparing them with public ratings. TMDB is used
for search, title details, seasons and episodes, and posters. The key is
used only by me, from my own phone; no data is resold, cached publicly or
redistributed, and the app shows TMDB attribution on its About screen.
Source code: https://github.com/tiltozavr2545/Framebook
```

**Контактные данные:**

| Поле | Что вписать |
|---|---|
| First Name / Last Name | имя и фамилия латиницей |
| Email Address | email аккаунта |
| Phone Number | номер в международном формате, с кодом страны (`+31…`, `+7…`) |
| Address 1 | улица и дом |
| Address 2 | можно оставить пустым |
| Zip Code | почтовый индекс |
| City | город |
| State / Province | регион; если в стране нет штатов — повторить город или регион |
| Country | страна |

Контакты нужны TMDB, чтобы связаться с владельцем ключа. Наружу они не
публикуются. Условия использования требуют достоверных данных, так что
заполняй правдиво. Указывать можно страну, где фактически живёшь.

5. **Submit**. Для Developer-ключа одобрение обычно мгновенное: после
   отправки откроется та же страница Settings → API, уже с ключами.

### 1.3. Какой ключ брать

На странице Settings → API два значения:

- **API Key** — короткий, 32 символа (`a1b2c3…`);
- **API Read Access Token** — длинный, начинается с `eyJ…`.

Права у них одинаковые. Брать **API Read Access Token**: он передаётся
заголовком, а не в адресе запроса, и не оседает в логах. Приложение
принимает и короткий ключ, если удобнее.

### 1.4. Проверка

```sh
curl -s https://api.themoviedb.org/3/movie/603 \
  -H "Authorization: Bearer ВАШ_ТОКЕН" | head -c 200
```

Должен прийти JSON с `"title":"The Matrix"`. Ответ
`"status_code":7` значит неверный ключ, `"status_code":34` — неверный id
фильма (то есть ключ работает).

### 1.5. Ограничения

- Только некоммерческое использование, атрибуция TMDB в приложении
  обязательна (она есть в «О приложении»).
- Дневного лимита нет, есть ограничение по частоте — порядка десятков
  запросов в секунду. Для одного человека недостижимо.

## 2. ПоискКино (рейтинг Кинопоиска)

Неофициальный API поверх данных Кинопоиска (бывший kinopoisk.dev). Ключ
выдаёт Telegram-бот, сайта с личным кабинетом нет.

1. Открыть бота **[@poiskkinodev_bot](https://t.me/poiskkinodev_bot)** и
   нажать **Start**.
2. Следовать подсказкам бота и выбрать бесплатный тариф — он называется
   **«Демо»** (200 запросов в сутки). Платные тарифы не нужны.
3. Бот пришлёт ключ — строку вида `ABCD123-EFGH456-…`. Скопировать её
   целиком.

Кнопки бота могут называться иначе, чем здесь: смысл — получить ключ на
бесплатном тарифе. Там же, в боте, смотреть остаток лимита и
перевыпускать ключ, если он утёк.

**Проверка** (тратит 1 из 200 запросов в сутки):

```sh
curl -s https://api.poiskkino.dev/v1.5/movie/301 \
  -H "X-API-KEY: ВАШ_КЛЮЧ" | head -c 200
```

Должен прийти JSON про «Матрицу» (`"id":301`). `401` — неверный ключ;
ошибка с упоминанием лимита — суточные запросы кончились, ключ заработает
снова на следующий день.

**Ограничения:** 200 запросов в сутки на ключ. Приложение расходует их
экономно (кэш, бюджет запросов — см. [external-sources.md](external-sources.md)),
но большая библиотека оценок наполняется рейтингом КП постепенно, за
несколько дней.

## 3. OMDb (IMDb, Rotten Tomatoes, Metacritic)

1. Открыть [omdbapi.com/apikey.aspx](https://www.omdbapi.com/apikey.aspx).
2. Account Type — **FREE! (1,000 daily limit)**. Patreon — платный, не
   нужен.
3. Заполнить:

   | Поле | Что вписать |
   |---|---|
   | Email | рабочий ящик — на него придёт ключ |
   | First Name / Last Name | имя и фамилия |
   | Use | `Personal non-commercial Android app to compare my own film ratings with IMDb, Rotten Tomatoes and Metacritic.` |

4. **Submit**. Придёт письмо с ключом (7–8 символов, например `1a2b3c4d`) и
   **ссылкой активации**. По ссылке **обязательно перейти**: до этого
   ключ отвечает ошибкой.
5. Письмо может идти до часа. Хуже всего доходит на Outlook, Hotmail и
   Live — лучше указать Gmail. Не пришло за час — проверить спам; если и
   там нет, автор сервиса просит написать ему напрямую (контакт — на
   omdbapi.com).

**Проверка:**

```sh
curl -s "https://www.omdbapi.com/?i=tt0133093&apikey=ВАШ_КЛЮЧ" | head -c 200
```

Должен прийти JSON с `"Title":"The Matrix"` и `"Response":"True"`.
`"Error":"Invalid API key!"` — ключ неверный или не активирован (см. п. 4),
`"Error":"Request limit reached!"` — лимит на сегодня исчерпан.

**Ограничения:** 1000 запросов в сутки; данные OMDb — CC BY-NC 4.0, то есть
только некоммерческое использование.

## 4. Куда вписать ключи

**В приложении:** при первом запуске — экран ввода ключей, потом
«Настройки → Источники». Приложение проверит каждый ключ пробным запросом и
сохранит его в защищённом хранилище телефона. В Google Drive при
синхронизации ключи не уходят — на новом телефоне их нужно ввести заново.

**Разработчику, для снятия фикстур** — в файл вне репозитория:

```sh
mkdir -p ~/.config/framebook
umask 077
nano ~/.config/framebook/keys.env
```

```sh
TMDB_TOKEN=eyJ...
POISKKINO_KEY=...
OMDB_KEY=...
```

Затем `scripts/capture-fixtures.sh` — подробнее в [operations.md](operations.md).

## 5. Безопасность ключей

- Ключ — личный. Не коммитить, не отправлять в чаты (в том числе в чат с
  AI-ассистентом), не публиковать на скриншотах.
- Утёк или засветился:
  - **ПоискКино** — перевыпустить в боте;
  - **OMDb** — запросить новый на той же странице (на другой email) и
    написать автору сервиса, чтобы отключил старый;
  - **TMDB** — поискать перевыпуск ключа в Settings → API; если его там
    нет — написать в поддержку TMDB.

  После этого вписать новый ключ в приложение и в `keys.env`.
- Чужие ключи друзьям не раздавать: лимиты считаются на ключ, а не на
  человека, и чужое приложение будет тратить твои 200 запросов ПоискКино.
