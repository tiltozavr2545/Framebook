# Changelog

История версий Framebook. Вынесена из AGENTS.md, чтобы тот не грузился
целиком в контекст на каждой сессии — здесь она читается по запросу, когда
действительно нужна.

Про **почему** конкретное решение принято именно так лучше смотреть не сюда, а
в документ, который это решение описывает (`docs/`), или в `git log`. Здесь —
хронология и что в какой версии появилось. Формат записи: что сделано, версия
в скобках; версия — `name+build` из `app/pubspec.yaml`.

Ход MVP по этапам — в [docs/implementation-plan.md](docs/implementation-plan.md).

## До первой версии

- Документация проекта: бриф, схема данных, внешние источники,
  синхронизация, устройство клиента, эксплуатация, план и отложенное
  (2026-10-19, кода ещё нет).
- Скелет приложения (0.0.1+1): Flutter-проект в `app/` на 3.32.8 с
  подобранными под него зависимостями, Android-сборка по образцу Amicus
  (SDK 36, AGP 8.9.3, отказ release-сборки без ключа подписи), Makefile,
  git-хуки, CI, скрипт снятия фикстур внешних API.
- Release-ключ подписи (в секретах GitHub и в копии вне репозитория) и
  workflow `release-apk.yml`: тег `vX.Y.Z` → подписанный APK в GitHub
  Release. Снят риск доступности TMDB из РФ — пользователи не выходят в
  сеть с российских IP (0.0.1+1).
- Фикстуры всех трёх API сняты живыми ключами, пометки «проверить» в
  `docs/external-sources.md` закрыты. Сопоставление с Кинопоиском
  переделано на «сначала imdb_id»: поиск по tmdb id смешивает фильмы и
  сериалы с одним номером. Пошаговая инструкция по ключам —
  `docs/api-keys.md` (0.0.1+1).
